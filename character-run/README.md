# character-run

Mała scena three.js (trzecioosobowa kontrola postaci, proceduralna animacja biegu na kościach).

Nie jest w repo (w `.gitignore`), trzeba dodać lokalnie:
- `assets/model.fbx` oraz `assets/textures/` (tekstury `T_RubySnapper_*`),
- `vendor/three/` (three.js r170: `npm i three@0.170.0`, skopiuj pakiet do `vendor/three`).

Uruchomienie: `npx http-server . -p 8080` i otwórz http://localhost:8080
